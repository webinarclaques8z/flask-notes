# flask-notes

A compact Flask service used as a reference for small JSON APIs: list, create and delete notes.

## Usage

```bash
pip install -r requirements.txt && python app.py
```

## Endpoints

- `GET /notes`
- `POST /notes` with `{"text": "..."}`
- `DELETE /notes/<id>`
